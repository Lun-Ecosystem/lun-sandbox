# Lun'Sandbox

> Projet de l'écosystème Lun'. Les règles communes (méthode, git, qualité, design) viennent du plugin
> `lun` et de [lun-docs](https://github.com/Lun-Ecosystem/lun-docs), qui font foi. Ce fichier ne garde
> que ce qui est propre à ce projet. 100 lignes maximum.

## Ce projet

- **Rôle** : dépôt jetable d'essai à blanc, hors registre.
- **Possède** : rien.
- **Ne possède pas** : tout le reste.

## Lancer en local

```bash
npm test
```

Prérequis : Node 22 ou plus. Aucune variable d'environnement.

## Spécificités

- Chaque travail passe par le skill `lun-chantier`, même trivial : c'est l'objet de l'essai.
